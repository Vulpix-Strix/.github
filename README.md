# Welcome to Vulpix Strix!

*Little worlds, strange ideas, and things worth playing.*

Vulpix-Strix is a small independent creative studio founded by [Cuervolu](https://cuervolu.dev).

It's a little creative corner where strange ideas turn into games, interactive experiences, imaginary worlds, and whatever else comes to mind.

We love telling stories, experimenting with unusual ideas, and creating things that are fun to explore.

Sometimes that means building a game. Sometimes it's making the tools to create one. And sometimes it's just following a weird idea to see where it goes.

Not everything has to make sense. Sometimes, it just has to be fun.

## What we're making

### [Glaux](https://github.com/Vulpix-Strix/glaux)

*The computer that wanted you to make games.*

A fantasy console inspired by a computer that never existed.

Create your own games, draw sprites, compose sounds, write code, and bring tiny worlds to life, all inside one little imaginary machine.
